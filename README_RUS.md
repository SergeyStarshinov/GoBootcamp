Группа учебных проектов для изучения языка Go

- T01: Проекты для изучение основ языка, базового синтаксиса, типов данных.
- T02: Проекты для знакомства с механизмами конкурентности в Go.
- P01: Проект консольной игры "бродилки" в духе классической игры Rogue. Командный проект
- T03: Backend часть веб-приложения игры в крестики-нолики, с реализацией логики игры за компьютер.
